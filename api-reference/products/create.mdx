<Info>
  `POST /v1/products` &nbsp;·&nbsp; Requer o escopo `products:write`
</Info>

Um **produto** é algo que você vende. Todo produto tem uma ou mais **ofertas** — formas de comprá-lo, cada uma com um preço. Este endpoint cria o produto e a primeira oferta juntos; essa oferta vira a padrão.

## Parâmetros do corpo

<ParamField body="name" type="string" required>
  Nome do produto, de 1 a 160 caracteres.
</ParamField>

<ParamField body="description" type="string">
  Até 2000 caracteres. Padrão: string vazia.
</ParamField>

<ParamField body="metadata" type="object">
  Pares chave–valor livres para seu uso.
</ParamField>

<ParamField body="default_offer" type="object" required>
  A primeira oferta do produto. Mesmo formato de [Criar uma oferta](/api-reference/offers/create), sem `is_default`.

  <Expandable title="propriedades de default_offer" defaultOpen>
    <ParamField body="default_offer.amount_minor" type="integer" required>
      Preço em unidades menores (centavos). De `1` a `99999999999`.
    </ParamField>
    <ParamField body="default_offer.currency" type="string" required>
      ISO 4217 em maiúsculas, ex. `BRL`.
    </ParamField>
    <ParamField body="default_offer.name" type="string">
      Rótulo da oferta, de 1 a 160 caracteres. Padrão: `"Padrão"`.
    </ParamField>
    <ParamField body="default_offer.compare_at_amount_minor" type="integer">
      Um preço de referência riscado. Deve ser `≥ amount_minor`.
    </ParamField>
    <ParamField body="default_offer.type" type="string" default="one_time">
      `one_time` ou `recurring`.
    </ParamField>
    <ParamField body="default_offer.billing_interval" type="string">
      `day`, `week`, `month` ou `year`. Obrigatório quando `type` é `recurring`; não permitido quando `one_time`.
    </ParamField>
    <ParamField body="default_offer.interval_count" type="integer">
      Intervalos entre cobranças, de `1` a `999`. Só para recorrente; padrão `1`.
    </ParamField>
  </Expandable>
</ParamField>

## Requisição

```bash cURL
curl --request POST https://api.moneydev.com.br/v1/products \
  --header "Authorization: Bearer $ACCESS_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{
    "name": "Plano Pro",
    "description": "Acesso completo por 12 meses",
    "default_offer": {
      "name": "Anual",
      "amount_minor": 49900,
      "currency": "BRL"
    }
  }'
```

## Resposta

## Erros

| Status | `code` | Causa |
|---|---|---|
| `400` | `invalid_request` | Validação falhou; `param` indica o campo |
| `400` | `invalid_product_name` | `name` ficou vazio após remover espaços |
| `400` | `invalid_compare_at_amount` | `default_offer.compare_at_amount_minor` é menor que `amount_minor` |
| `400` | `billing_interval_required` | `default_offer.type` é `recurring` sem `billing_interval` |
| `400` | `invalid_one_time_billing` | Uma oferta `one_time` informou `billing_interval` ou `interval_count` |

## Objeto de produto

<ResponseField name="id" type="string">ID do produto, com prefixo `prod_`.</ResponseField>
<ResponseField name="object" type="string">Sempre `"product"`.</ResponseField>
<ResponseField name="name" type="string">Nome do produto.</ResponseField>
<ResponseField name="description" type="string">Descrição, ou `""`.</ResponseField>
<ResponseField name="status" type="string">`active` ou `archived`.</ResponseField>
<ResponseField name="metadata" type="object">Seus metadados.</ResponseField>
<ResponseField name="default_offer" type="object | null">
  A [oferta](/api-reference/offers/create#objeto-de-oferta) padrão atual, ou `null` se nenhuma estiver ativa.
</ResponseField>
<ResponseField name="created_at" type="string">Data/hora de criação em ISO 8601.</ResponseField>
<ResponseField name="updated_at" type="string">Data/hora da última alteração em ISO 8601.</ResponseField>

---

<Info>
  `GET /v1/products/{productId}` &nbsp;·&nbsp; Requer o escopo `products:read`
</Info>

## Parâmetros de caminho

<ParamField path="productId" type="string" required>
  O ID do produto, ex. `prod_4d5e6f7a-8b9c-4d0e-1f2a-3b4c5d6e7f8a`. Se não for um ID `prod_` válido → `400` (`invalid_product_id`).
</ParamField>

## Requisição

```bash cURL
curl https://api.moneydev.com.br/v1/products/prod_4d5e6f7a-8b9c-4d0e-1f2a-3b4c5d6e7f8a \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

## Resposta

`200 OK` com o [objeto de produto](/api-reference/products/create#objeto-de-produto), incluindo a `default_offer` atual (ou `null`).

## Erros

| Status | `code` | Causa |
|---|---|---|
| `400` | `invalid_product_id` | O trecho do caminho não é um ID `prod_` válido |
| `404` | `product_not_found` | Não existe esse produto na sua conta |

<Tip>
  Para listar todos os preços de um produto, use [Listar ofertas](/api-reference/offers/list).
</Tip>

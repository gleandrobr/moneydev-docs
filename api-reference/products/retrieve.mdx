---
title: "Retrieve a product"
sidebarTitle: "Retrieve product"
description: "Fetch a single product by ID, with its default offer."
---

<Info>
  `GET /v1/products/{productId}` &nbsp;·&nbsp; Requires scope `products:read`
</Info>

## Path parameters

<ParamField path="productId" type="string" required>
  The product ID, e.g. `prod_4d5e6f7a-8b9c-4d0e-1f2a-3b4c5d6e7f8a`. Not a valid `prod_` ID → `400` (`invalid_product_id`).
</ParamField>

## Request

```bash cURL
curl https://api.moneydev.com.br/v1/products/prod_4d5e6f7a-8b9c-4d0e-1f2a-3b4c5d6e7f8a \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

## Response

`200 OK` with the [product object](/api-reference/products/create#product-object), including its current `default_offer` (or `null`).

## Errors

| Status | `code` | Cause |
|---|---|---|
| `400` | `invalid_product_id` | The path segment is not a valid `prod_` ID |
| `404` | `product_not_found` | No such product on your account |

<Tip>
  To list every price for a product, use [List offers](/api-reference/offers/list).
</Tip>

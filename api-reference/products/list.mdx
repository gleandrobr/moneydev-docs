<Info>
  `GET /v1/products` &nbsp;·&nbsp; Requires scope `products:read`
</Info>

Returns your products, newest first, in a [list object](/api-reference/pagination). Each entry includes its current `default_offer`.

## Query parameters

<ParamField query="limit" type="integer" default="20">
  Records to return, `1`–`100`.
</ParamField>

<ParamField query="starting_after" type="string">
  A product ID (`prod_…`) to page after. Malformed or unknown returns `400` (`invalid_cursor`).
</ParamField>

## Request

```bash cURL
curl "https://api.moneydev.com.br/v1/products?limit=1" \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

<Info>
  `GET /v1/products` &nbsp;·&nbsp; Requer o escopo `products:read`
</Info>

Retorna seus produtos, mais recentes primeiro, em um [objeto de lista](/api-reference/pagination). Cada item inclui a `default_offer` atual.

## Parâmetros de query

<ParamField query="limit" type="integer" default="20">
  Registros a retornar, de `1` a `100`.
</ParamField>

<ParamField query="starting_after" type="string">
  Um ID de produto (`prod_…`) a partir do qual paginar. Malformado ou desconhecido retorna `400` (`invalid_cursor`).
</ParamField>

## Requisição

```bash cURL
curl "https://api.moneydev.com.br/v1/products?limit=1" \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

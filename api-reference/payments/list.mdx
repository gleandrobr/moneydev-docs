---
title: "List Payments — Filter by Status, Method, and Date"
sidebarTitle: "List Payments"
description: "Retrieve a paginated list of payments filtered by status, method, customer, or date range. Navigate pages with cursor-based pagination."
---

Use this endpoint to retrieve a paginated list of all payments in your MoneyDev account. You can narrow results using filters for status, payment method, customer, and creation date range. Results are ordered by creation date, most recent first. MoneyDev uses cursor-based pagination — use the `after` and `before` cursors from the response `meta` object to navigate between pages.

## Endpoint

```
GET https://api.moneydev.com.br/v1/payments
```

## Request

### Headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer YOUR_API_KEY` |

### Query Parameters

<ParamField query="limit" type="integer" default="20">
  The maximum number of payments to return per page. Accepts a value between `1` and `100`.
</ParamField>

<ParamField query="after" type="string">
  A pagination cursor returned in the previous response's `meta.cursor.after` field. Use this to fetch the next page of results.
</ParamField>

<ParamField query="before" type="string">
  A pagination cursor returned in the previous response's `meta.cursor.before` field. Use this to fetch the previous page of results.
</ParamField>

<ParamField query="status" type="string">
  Filter payments by status. Accepted values: `pending`, `authorized`, `paid`, `failed`, `refunded`, `partially_refunded`, `expired`, `cancelled`.
</ParamField>

<ParamField query="method" type="string">
  Filter payments by payment method. Accepted values: `pix`, `boleto`, `credit_card`, `debit_card`.
</ParamField>

<ParamField query="customer_id" type="string">
  Filter payments by customer ID (`cus_...`). Returns only payments associated with that customer.
</ParamField>

<ParamField query="created_after" type="string">
  Return only payments created at or after this ISO 8601 datetime (e.g., `"2025-07-01T00:00:00Z"`).
</ParamField>

<ParamField query="created_before" type="string">
  Return only payments created at or before this ISO 8601 datetime (e.g., `"2025-07-31T23:59:59Z"`).
</ParamField>

## Code Example

```bash cURL
curl --request GET \
  --url 'https://api.moneydev.com.br/v1/payments?limit=10&status=paid&method=pix&created_after=2025-07-01T00%3A00%3A00Z' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

## Response

The response is a paginated envelope containing a `data` array of payment objects and a `meta` object with pagination information.

### Response Fields

<ResponseField name="data" type="array">
  An array of payment objects. Each item contains the same fields as the [Retrieve Payment](/api-reference/payments/retrieve) response, including `id`, `status`, `method`, `amount`, `currency`, `net_amount`, `fee`, `customer`, `created_at`, `paid_at`, and method-specific objects (`pix`, `boleto`, or `card`).
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for the current result set.

  <Expandable title="meta fields">
    <ResponseField name="meta.has_more" type="boolean">
      `true` if there are additional results beyond the current page. Use the `after` cursor to fetch them.
    </ResponseField>
    <ResponseField name="meta.total" type="integer">
      The total number of payments matching your filters, across all pages.
    </ResponseField>
    <ResponseField name="meta.cursor" type="object">
      <Expandable title="cursor fields">
        <ResponseField name="meta.cursor.after" type="string">
          Pass this value as the `after` query parameter to fetch the next page. `null` if you are on the last page.
        </ResponseField>
        <ResponseField name="meta.cursor.before" type="string">
          Pass this value as the `before` query parameter to fetch the previous page. `null` if you are on the first page.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

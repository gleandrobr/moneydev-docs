<Info>
  `GET /v1/me` &nbsp;·&nbsp; Requer qualquer token de acesso válido — sem escopo específico.
</Info>

Retorna a conta do seller sobre a qual o token atua e o cliente de API para o qual ele foi emitido. Útil como teste de conectividade e de credenciais.

## Requisição

```bash cURL
curl https://api.moneydev.com.br/v1/me \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

## Resposta

<ResponseField name="seller" type="object">
  <Expandable title="propriedades" defaultOpen>
    <ResponseField name="seller.id" type="string">
      ID do seller, com prefixo `seller_`.
    </ResponseField>
    <ResponseField name="seller.name" type="string">
      Nome de exibição da conta do seller.
    </ResponseField>
    <ResponseField name="seller.status" type="string">
      Sempre `active` — tokens só são emitidos para sellers ativos.
    </ResponseField>
    <ResponseField name="seller.default_currency" type="string">
      Moeda ISO 4217 em que a conta liquida, ex. `BRL`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api_client" type="object">
  <Expandable title="propriedades" defaultOpen>
    <ResponseField name="api_client.id" type="string">
      ID do cliente de API, com prefixo `client_`.
    </ResponseField>
    <ResponseField name="api_client.name" type="string">
      Rótulo dado ao cliente no Dashboard.
    </ResponseField>
    <ResponseField name="api_client.client_id" type="string">
      O `client_id` OAuth usado para obter o token.
    </ResponseField>
    <ResponseField name="api_client.scopes" type="string[]">
      Escopos carregados pelo token de acesso atual.
    </ResponseField>
  </Expandable>
</ResponseField>

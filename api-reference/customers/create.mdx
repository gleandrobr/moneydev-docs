<Info>
  `POST /v1/customers` &nbsp;·&nbsp; Requires scope `customers:write`
</Info>

Creates a customer for your account. Attach one to a [checkout](/api-reference/checkouts/create) with `customer_id` so you don't resend buyer details each time.

## Body parameters

<ParamField body="name" type="string" required>
  Customer's full name or company name. 1–160 characters.
</ParamField>

<ParamField body="email" type="string" required>
  Valid email address, up to 320 characters. Stored lowercased. Must be unique within your account.
</ParamField>

<ParamField body="phone" type="string">
  Phone number, 1–32 characters. E.164 (`+5511999999999`) recommended.
</ParamField>

<ParamField body="tax_id" type="string">
  CPF or CNPJ, 1–32 characters. Sent as-is — digits only or formatted.
</ParamField>

<ParamField body="metadata" type="object">
  Arbitrary key–value pairs for your own use. Returned on every representation of the customer.
</ParamField>

Unknown fields cause a `400` (`invalid_request`).

## Request

```bash cURL
curl --request POST https://api.moneydev.com.br/v1/customers \
  --header "Authorization: Bearer $ACCESS_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{
    "name": "João da Silva",
    "email": "joao.silva@example.com",
    "phone": "+5511999999999",
    "tax_id": "12345678909",
    "metadata": { "user_id": "usr_789" }
  }'
```

## Response

`201 Created` with the [customer object](#customer-object).

```json
{
  "id": "cus_9b2c4f1a-3d5e-4a7b-8c9d-1e2f3a4b5c6d",
  "object": "customer",
  "name": "João da Silva",
  "email": "joao.silva@example.com",
  "phone": "+5511999999999",
  "tax_id": "12345678909",
  "status": "active",
  "metadata": { "user_id": "usr_789" },
  "created_at": "2026-08-28T13:00:00.000Z",
  "updated_at": "2026-08-28T13:00:00.000Z"
}
```

## Errors

| Status | `code` | Cause |
|---|---|---|
| `400` | `invalid_request` | Validation failed; `param` names the field |
| `400` | `invalid_customer_name` | `name` is empty after trimming |
| `409` | `customer_email_already_exists` | Another customer on your account uses that email |

## Customer object

<ResponseField name="id" type="string">Customer ID, prefixed `cus_`.</ResponseField>
<ResponseField name="object" type="string">Always `"customer"`.</ResponseField>
<ResponseField name="name" type="string">Full or company name.</ResponseField>
<ResponseField name="email" type="string">Email address, lowercased.</ResponseField>
<ResponseField name="phone" type="string | null">Phone number, or `null`.</ResponseField>
<ResponseField name="tax_id" type="string | null">CPF or CNPJ, or `null`.</ResponseField>
<ResponseField name="status" type="string">`active` or `inactive`. New customers are `active`.</ResponseField>
<ResponseField name="metadata" type="object">Your metadata. `{}` if none was set.</ResponseField>
<ResponseField name="created_at" type="string">ISO 8601 creation timestamp.</ResponseField>
<ResponseField name="updated_at" type="string">ISO 8601 timestamp of the last change.</ResponseField>

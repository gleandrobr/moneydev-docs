<Info>
  `GET /v1/customers` &nbsp;·&nbsp; Requer o escopo `customers:read`
</Info>

Retorna os seus clientes, mais recentes primeiro, em um [objeto de lista](/api-reference/pagination).

## Parâmetros de query

<ParamField query="limit" type="integer" default="20">
  Registros a retornar, de `1` a `100`.
</ParamField>

<ParamField query="starting_after" type="string">
  Um ID de cliente (`cus_…`) a partir do qual paginar. Um valor desconhecido ou malformado retorna `400` (`invalid_cursor`).
</ParamField>

## Requisição

```bash cURL
curl "https://api.moneydev.com.br/v1/customers?limit=2" \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

<Info>
  `GET /v1/customers` &nbsp;·&nbsp; Requires scope `customers:read`
</Info>

Returns your customers, newest first, in a [list object](/api-reference/pagination).

## Query parameters

<ParamField query="limit" type="integer" default="20">
  Records to return, `1`–`100`.
</ParamField>

<ParamField query="starting_after" type="string">
  A customer ID (`cus_…`) to page after. An unknown or malformed value returns `400` (`invalid_cursor`).
</ParamField>

## Request

```bash cURL
curl "https://api.moneydev.com.br/v1/customers?limit=2" \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

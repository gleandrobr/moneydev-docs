title: "List All Customers — Filter by Email or Date Range"

---

Use this endpoint to retrieve a paginated list of all customers in your MoneyDev account. You can filter the results by email address or restrict them to a specific creation date range. Results are ordered by creation date, most recent first. MoneyDev uses cursor-based pagination — use the `after` and `before` values from the response `meta.cursor` object to move between pages.

## Endpoint

```
GET https://api.moneydev.com.br/v1/customers
```

## Request

### Headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer YOUR_API_KEY` |

### Query Parameters

<ParamField query="limit" type="integer" default="20">
  The maximum number of customers to return per page. Accepts a value between `1` and `100`.
</ParamField>

<ParamField query="after" type="string">
  A pagination cursor from the previous response's `meta.cursor.after` field. Pass this to retrieve the next page of results.
</ParamField>

<ParamField query="before" type="string">
  A pagination cursor from the previous response's `meta.cursor.before` field. Pass this to retrieve the previous page of results.
</ParamField>

<ParamField query="email" type="string">
  Filter customers by exact email address. Useful for looking up whether a customer already exists before creating a new one.
</ParamField>

<ParamField query="created_after" type="string">
  Return only customers created at or after this ISO 8601 datetime (e.g., `"2025-07-01T00:00:00Z"`).
</ParamField>

<ParamField query="created_before" type="string">
  Return only customers created at or before this ISO 8601 datetime (e.g., `"2025-07-31T23:59:59Z"`).
</ParamField>

## Code Example

```bash cURL
curl --request GET \
  --url 'https://api.moneydev.com.br/v1/customers?limit=20&created_after=2025-07-01T00%3A00%3A00Z' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

## Response

The response is a paginated envelope containing a `data` array of customer objects and a `meta` object with pagination details.

### Response Fields

<ResponseField name="data" type="array">
  An array of customer objects. Each item contains the same fields as the [Retrieve Customer](/api-reference/customers/retrieve) response: `id`, `name`, `email`, `cpf`, `cnpj`, `phone`, `address`, `cards`, `metadata`, and `created_at`.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for the current result set.

  <Expandable title="meta fields">
    <ResponseField name="meta.has_more" type="boolean">
      `true` if there are more customers beyond the current page. Pass `meta.cursor.after` as the `after` parameter to fetch them.
    </ResponseField>
    <ResponseField name="meta.total" type="integer">
      Total number of customers matching your filters, across all pages.
    </ResponseField>
    <ResponseField name="meta.cursor" type="object">
      <Expandable title="cursor fields">
        <ResponseField name="meta.cursor.after" type="string">
          Pass as the `after` query parameter to retrieve the next page. `null` when on the last page.
        </ResponseField>
        <ResponseField name="meta.cursor.before" type="string">
          Pass as the `before` query parameter to retrieve the previous page. `null` when on the first page.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "Update a Customer Profile — Partial Updates Allowed"
sidebarTitle: "Update Customer"
description: "Update an existing customer's name, email, phone, address, or metadata. Only the fields you send are changed; CPF and CNPJ are immutable."
---

Use this endpoint to update an existing customer's profile. The update is applied as a **partial update (PATCH-style)**: only the fields you include in the request body are changed — any fields you omit remain exactly as they are. This makes it safe to update a single field, such as a phone number, without having to re-send the customer's full profile.

<Note>
  **CPF and CNPJ cannot be changed after creation.** Once a customer has been created with a `cpf` or `cnpj`, those fields are locked to prevent data integrity issues with payment records and regulatory compliance. If you need to correct a tax ID, create a new customer profile. Any attempt to update `cpf` or `cnpj` on an existing customer will return a `422 Unprocessable Entity` error.
</Note>

## Endpoint

```
PUT https://api.moneydev.com.br/v1/customers/:id
```

## Request

### Headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer YOUR_API_KEY` |
| `Content-Type` | `application/json` |

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the customer to update (`cus_...`).
</ParamField>

### Body Parameters

All fields are optional. Include only the fields you want to update.

<ParamField body="name" type="string">
  The customer's updated full name or company name.
</ParamField>

<ParamField body="email" type="string">
  The customer's updated email address. Must be a valid email format.
</ParamField>

<ParamField body="phone" type="string">
  The customer's updated phone number in **E.164 format** (e.g., `"+5511988887777"`).
</ParamField>

<ParamField body="address" type="object">
  An updated address for the customer. When you provide this field, the entire address object is replaced — partial address updates are not supported.

  <Expandable title="address fields">
    <ParamField body="address.street" type="string">
      Street name.
    </ParamField>
    <ParamField body="address.number" type="string">
      Street number.
    </ParamField>
    <ParamField body="address.complement" type="string">
      Address complement (apartment, suite, etc.).
    </ParamField>
    <ParamField body="address.district" type="string">
      Neighborhood or district.
    </ParamField>
    <ParamField body="address.city" type="string">
      City name.
    </ParamField>
    <ParamField body="address.state" type="string">
      Two-letter Brazilian state abbreviation (e.g., `"SP"`).
    </ParamField>
    <ParamField body="address.zip_code" type="string">
      Brazilian postal code (CEP), digits only (e.g., `"04538133"`).
    </ParamField>
    <ParamField body="address.country" type="string">
      ISO 3166-1 alpha-2 country code. Defaults to `"BR"`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="metadata" type="object">
  Updated key-value metadata. When provided, the entire metadata object is **replaced** (not merged). Pass `{}` to clear all metadata.
</ParamField>

## Code Example

```bash cURL
curl --request PUT \
  --url https://api.moneydev.com.br/v1/customers/cus_01HABC789XYZ \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "phone": "+5511988887777",
    "address": {
      "street": "Rua Oscar Freire",
      "number": "500",
      "complement": "Casa",
      "district": "Jardins",
      "city": "São Paulo",
      "state": "SP",
      "zip_code": "01426001",
      "country": "BR"
    }
  }'
```

## Response

The response is the full updated customer object, reflecting all fields including those you did not change.

### Response Fields

<ResponseField name="id" type="string">
  Unique customer identifier with the prefix `cus_`.
</ResponseField>

<ResponseField name="name" type="string">
  The customer's full name or company name.
</ResponseField>

<ResponseField name="email" type="string">
  The customer's email address.
</ResponseField>

<ResponseField name="cpf" type="string">
  The customer's individual tax ID (CPF). `null` if not stored.
</ResponseField>

<ResponseField name="cnpj" type="string">
  The customer's company tax ID (CNPJ). `null` if not stored.
</ResponseField>

<ResponseField name="phone" type="string">
  The customer's phone number in E.164 format. `null` if not stored.
</ResponseField>

<ResponseField name="address" type="object">
  The customer's current address. `null` if no address is stored.
</ResponseField>

<ResponseField name="cards" type="array">
  An array of tokenized cards saved to this customer's profile.
</ResponseField>

<ResponseField name="metadata" type="object">
  The current metadata object. Returns an empty object `{}` if none is stored.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the customer was originally created.
</ResponseField>

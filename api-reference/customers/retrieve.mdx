---
title: "Retrieve a customer"
sidebarTitle: "Retrieve customer"
description: "Fetch a single customer by ID."
---

<Info>
  `GET /v1/customers/{customerId}` &nbsp;·&nbsp; Requires scope `customers:read`
</Info>

## Path parameters

<ParamField path="customerId" type="string" required>
  The customer ID, e.g. `cus_9b2c4f1a-3d5e-4a7b-8c9d-1e2f3a4b5c6d`. A value that isn't a well-formed `cus_` ID returns `400` (`invalid_customer_id`).
</ParamField>

## Request

```bash cURL
curl https://api.moneydev.com.br/v1/customers/cus_9b2c4f1a-3d5e-4a7b-8c9d-1e2f3a4b5c6d \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

## Response

`200 OK` with the [customer object](/api-reference/customers/create#customer-object).

```json
{
  "id": "cus_9b2c4f1a-3d5e-4a7b-8c9d-1e2f3a4b5c6d",
  "object": "customer",
  "name": "João da Silva",
  "email": "joao.silva@example.com",
  "phone": "+5511999999999",
  "tax_id": "12345678909",
  "status": "active",
  "metadata": { "user_id": "usr_789" },
  "created_at": "2026-08-28T13:00:00.000Z",
  "updated_at": "2026-08-28T13:00:00.000Z"
}
```

## Errors

| Status | `code` | Cause |
|---|---|---|
| `400` | `invalid_customer_id` | The path segment is not a valid `cus_` ID |
| `404` | `customer_not_found` | No such customer on your account |

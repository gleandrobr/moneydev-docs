<Info>
  `GET /v1/customers/{customerId}` &nbsp;·&nbsp; Requer o escopo `customers:read`
</Info>

## Parâmetros de caminho

<ParamField path="customerId" type="string" required>
  O ID do cliente, ex. `cus_9b2c4f1a-3d5e-4a7b-8c9d-1e2f3a4b5c6d`. Um valor que não seja um ID `cus_` bem formado retorna `400` (`invalid_customer_id`).
</ParamField>

## Requisição

```bash cURL
curl https://api.moneydev.com.br/v1/customers/cus_9b2c4f1a-3d5e-4a7b-8c9d-1e2f3a4b5c6d \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

## Resposta

`200 OK` com o [objeto de cliente](/api-reference/customers/create#objeto-de-cliente).

```json
{
  "id": "cus_9b2c4f1a-3d5e-4a7b-8c9d-1e2f3a4b5c6d",
  "object": "customer",
  "name": "João da Silva",
  "email": "joao.silva@example.com",
  "phone": "+5511999999999",
  "tax_id": "12345678909",
  "status": "active",
  "metadata": { "user_id": "usr_789" },
  "created_at": "2026-08-28T13:00:00.000Z",
  "updated_at": "2026-08-28T13:00:00.000Z"
}
```

## Erros

| Status | `code` | Causa |
|---|---|---|
| `400` | `invalid_customer_id` | O trecho do caminho não é um ID `cus_` válido |
| `404` | `customer_not_found` | Não existe esse cliente na sua conta |

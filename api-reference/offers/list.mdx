<Info>
  `GET /v1/products/{productId}/offers` &nbsp;·&nbsp; Requires scope `products:read`
</Info>

Returns a product's offers, newest first, in a [list object](/api-reference/pagination). Archived offers are excluded.

## Path parameters

<ParamField path="productId" type="string" required>
  The product ID. Not a valid `prod_` ID → `400` (`invalid_product_id`); unknown product → `404` (`product_not_found`).
</ParamField>

## Query parameters

<ParamField query="limit" type="integer" default="20">
  Records to return, `1`–`100`.
</ParamField>

<ParamField query="starting_after" type="string">
  An offer ID (`offer_…`) to page after.
</ParamField>

## Request

```bash cURL
curl "https://api.moneydev.com.br/v1/products/prod_4d5e6f7a-8b9c-4d0e-1f2a-3b4c5d6e7f8a/offers" \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

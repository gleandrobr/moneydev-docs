<Info>
  `GET /v1/products/{productId}/offers` &nbsp;·&nbsp; Requer o escopo `products:read`
</Info>

Retorna as ofertas de um produto, mais recentes primeiro, em um [objeto de lista](/api-reference/pagination). Ofertas arquivadas são omitidas.

## Parâmetros de caminho

<ParamField path="productId" type="string" required>
  O ID do produto. Se não for um ID `prod_` válido → `400` (`invalid_product_id`); produto desconhecido → `404` (`product_not_found`).
</ParamField>

## Parâmetros de query

<ParamField query="limit" type="integer" default="20">
  Registros a retornar, de `1` a `100`.
</ParamField>

<ParamField query="starting_after" type="string">
  Um ID de oferta (`offer_…`) a partir do qual paginar.
</ParamField>

## Requisição

```bash cURL
curl "https://api.moneydev.com.br/v1/products/prod_4d5e6f7a-8b9c-4d0e-1f2a-3b4c5d6e7f8a/offers" \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

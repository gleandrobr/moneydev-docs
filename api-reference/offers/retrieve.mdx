<Info>
  `GET /v1/offers/{offerId}` &nbsp;·&nbsp; Requires scope `products:read`
</Info>

Fetches an offer directly by ID — no product ID needed.

## Path parameters

<ParamField path="offerId" type="string" required>
  The offer ID, e.g. `offer_b2c3d4e5-f6a7-4b8c-9d0e-1f2a3b4c5d6e`. Not a valid `offer_` ID → `400` (`invalid_offer_id`).
</ParamField>

## Request

```bash cURL
curl https://api.moneydev.com.br/v1/offers/offer_b2c3d4e5-f6a7-4b8c-9d0e-1f2a3b4c5d6e \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

## Response

`200 OK` with the [offer object](/api-reference/offers/create#offer-object).

## Errors

| Status | `code` | Cause |
|---|---|---|
| `400` | `invalid_offer_id` | The path segment is not a valid `offer_` ID |
| `404` | `offer_not_found` | No such offer on your account, or it is archived |

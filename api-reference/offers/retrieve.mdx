<Info>
  `GET /v1/offers/{offerId}` &nbsp;·&nbsp; Requer o escopo `products:read`
</Info>

Busca uma oferta diretamente pelo ID — sem precisar do ID do produto.

## Parâmetros de caminho

<ParamField path="offerId" type="string" required>
  O ID da oferta, ex. `offer_b2c3d4e5-f6a7-4b8c-9d0e-1f2a3b4c5d6e`. Se não for um ID `offer_` válido → `400` (`invalid_offer_id`).
</ParamField>

## Requisição

```bash cURL
curl https://api.moneydev.com.br/v1/offers/offer_b2c3d4e5-f6a7-4b8c-9d0e-1f2a3b4c5d6e \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

## Resposta

`200 OK` com o [objeto de oferta](/api-reference/offers/create#objeto-de-oferta).

## Erros

| Status | `code` | Causa |
|---|---|---|
| `400` | `invalid_offer_id` | O trecho do caminho não é um ID `offer_` válido |
| `404` | `offer_not_found` | Não existe essa oferta na sua conta, ou ela está arquivada |

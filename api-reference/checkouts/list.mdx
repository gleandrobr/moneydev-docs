<Info>
  `GET /v1/checkouts` &nbsp;·&nbsp; Requer o escopo `checkouts:read`
</Info>

Retorna suas sessões de checkout, mais recentes primeiro, em um [objeto de lista](/api-reference/pagination). Qualquer sessão `open` que passou do `expires_at` é marcada como `expired` antes do retorno.

## Parâmetros de query

<ParamField query="limit" type="integer" default="20">
  Registros a retornar, de `1` a `100`.
</ParamField>

<ParamField query="starting_after" type="string">
  Um ID de checkout (`checkout_…`) a partir do qual paginar.
</ParamField>

## Requisição

```bash cURL
curl "https://api.moneydev.com.br/v1/checkouts?limit=1" \
  --header "Authorization: Bearer $ACCESS_TOKEN"
```

Welcome to MoneyDev — a payments gateway built for Brazil. Its REST API lets you register customers, model what you sell as products and offers, and open hosted checkout sessions where buyers pay with Pix.

## How it works

<Steps>
  <Step title="Create an API client">
    In the [Dashboard](https://dashboard.moneydev.com.br) → **API Keys**, create a client. You get a `client_id` and a `client_secret`.
  </Step>
  <Step title="Get an access token">
    Exchange those credentials at `POST /oauth/token` for a Bearer access token (valid 15 minutes). See [Authentication](/api-reference/authentication).
  </Step>
  <Step title="Model what you sell">
    Create a [product](/api-reference/products/create) and an [offer](/api-reference/offers/create) — an offer is a price (one-time or recurring) for a product.
  </Step>
  <Step title="Open a checkout and collect payment">
    [Create a checkout](/api-reference/checkouts/create) for an offer, redirect the buyer to its `checkout_url`, and poll the checkout until `status` is `completed`.
  </Step>
</Steps>

<Note>
  The developer API covers customers, products, offers, and checkouts. Payment itself happens on the hosted checkout page at `pay.moneydev.com.br`, backed by Pix.
</Note>

This walks the full path: get an access token, model what you sell, open a checkout, and collect a Pix payment on the hosted page.

<Tip>
  Every call goes to `https://api.moneydev.com.br`. Set `MONEYDEV_CLIENT_ID` and `MONEYDEV_CLIENT_SECRET` from your [Dashboard](https://dashboard.moneydev.com.br) API client first.
</Tip>

<Steps>
  <Step title="Get an access token">
    ```bash
    curl --request POST https://api.moneydev.com.br/oauth/token \
      --user "$MONEYDEV_CLIENT_ID:$MONEYDEV_CLIENT_SECRET" \
      --header "Content-Type: application/x-www-form-urlencoded" \
      --data grant_type=client_credentials
    ```

    Copy `access_token` from the response into `ACCESS_TOKEN`. It lasts 15 minutes. See [Authentication](/authentication) for details.
  </Step>

  <Step title="Create a product and its offer">
    A **product** is what you sell; an **offer** is a price for it. Create both at once. Amounts are in centavos — `49900` is R$ 499,00.

    ```bash
    curl --request POST https://api.moneydev.com.br/v1/products \
      --header "Authorization: Bearer $ACCESS_TOKEN" \
      --header "Content-Type: application/json" \
      --data '{
        "name": "Plano Pro",
        "default_offer": { "name": "Anual", "amount_minor": 49900, "currency": "BRL" }
      }'
    ```

    The response includes `default_offer.id` (an `offer_…`). Keep it for the next step.
  </Step>

  <Step title="(Optional) Create a customer">
    Attach a customer so you don't resend buyer details later.

    ```bash
    curl --request POST https://api.moneydev.com.br/v1/customers \
      --header "Authorization: Bearer $ACCESS_TOKEN" \
      --header "Content-Type: application/json" \
      --data '{ "name": "João da Silva", "email": "joao.silva@example.com" }'
    ```
  </Step>

  <Step title="Open a checkout">
    ```bash
    curl --request POST https://api.moneydev.com.br/v1/checkouts \
      --header "Authorization: Bearer $ACCESS_TOKEN" \
      --header "Content-Type: application/json" \
      --data '{
        "offer_id": "offer_a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d",
        "external_id": "order_1042",
        "success_url": "https://loja.example.com/pedido/1042/ok"
      }'
    ```

    The response has a `checkout_url` on `pay.moneydev.com.br` and `status: "open"`.
  </Step>

  <Step title="Send the buyer to pay">
    Redirect the buyer to `checkout_url`. They pay with Pix on the hosted page and land back on your `success_url`.
  </Step>

  <Step title="Confirm the payment">
    Poll the checkout until `status` is `completed`:

    ```bash
    curl https://api.moneydev.com.br/v1/checkouts/checkout_7f8a9b0c-1d2e-4f3a-8b4c-5d6e7f8a9b0c \
      --header "Authorization: Bearer $ACCESS_TOKEN"
    ```

    | `status` | Meaning |
    |---|---|
    | `open` | Awaiting payment |
    | `completed` | Paid — fulfil the order |
    | `expired` | 24 h passed with no payment |
    | `canceled` | Canceled before payment |

    <Note>
      A seller-facing webhook for `completed` is planned. For now, poll this endpoint.
    </Note>
  </Step>
</Steps>
